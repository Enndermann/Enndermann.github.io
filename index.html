25.06.10

Zlibrary

网址就不贴了。Zlib真的是对我影响深远的一个网站之一，极大地降低了我获取图书资源的难度，这或许就是知识平权的最好体现吧。

全球光污染地图

这个网站很有意思，据说许多天文爱好者就是看这个地图找合适的观星点的。看了一下，至少我这里是看不到太多星星了。

中国历史地图集

中国历史地图集是一个将谭其骧主编的同名地图集数字化的网站。谭图貌似在历史地图界有着相当高的地位。这个网站在我看一些历史书时棒了许多忙了。

默沙东诊疗手册大众版

默沙东诊疗手册大众版是一个医学科普网站，感觉很权威的样子，而且搜索十分友好。对于我这样的医学小白来说太需要一个靠谱的日常医疗手册了。

IPSOS

益普索，一家用户洞察与策略咨询公司，张vv推荐的研报机构！

LINUX DO

“真诚、友善、团结、专业，共建你我引以为荣之社区”是这家论坛的座右铭。实际上干货量是很多的，尤其是关于AI的资讯十分及时，还有一些瞎折腾的教程也很有意思。

quicker

quicker是一款指尖工具箱，可以创建或导入各种各样有意思的脚本。我常用的脚本有长截图、破除网页复制限制和模拟打字粘贴（后两者不知道帮我逃过了多少大学中形式主义的任务。感谢quicker。

FuckZHS

FuckZHS是一个Github开源项目，可以看到这个名字十分具有侵略性。它可以挂在后台帮我们刷智慧树课程，也曾帮了我的大忙，遗憾的是该项目没有前端界面。感谢FuckZHS。

Typora

Typora is a simple yet powerful Markdown reader.正如官网介绍的那样，Typora的简洁快速、对Markdown和$LaTex$的支持是它成为我常用编辑器的重要原因。

PiliPlus

PiliPlus是一个B站的安卓第三方客户端，本人正在使用，感觉PiliPlus的推荐质量要比原生B站高那么一些，并且还支持根据时长、关键词屏蔽视频，再加上更加简洁的界面、无广告、快速的响应，让我爱不释手。

累了，暂时就这些，持续更新~

GKD

GKD是一款基于无障碍，高级选择器，订阅规则的自定义屏幕点击 Android 应用。如果觉得每次打开京东淘宝b站要等两秒钟广告很心烦，而且乐意折腾，GKD是一个好的选择。
不过我在实际使用过程中，尽管给了GKD自启动的权限，但是它在后台经常退出，目前没找到办法。

阿里巴巴矢量图标库

https://www.iconfont.cn/
免费，素材数量多，素材导出格式多，制作PPT时的好帮手。

秘塔AI搜索

秘塔是一个国产AI搜索引擎，是我在查选修课资料时发现的。相比于chatgpt，豆包等通用大模型的搜索能力，幻觉更少，而且引用质量更高。更重要的是一天有100次免费次数，很爽好吧。

RSS订阅教程

发表于 2025-05-12 更新于 2025-05-20 分类于 教程 本文字数： 516 阅读时长 ≈ 2 分钟

简易信息聚合（RSS）是一种基于XML的标准，在互联网上被广泛采用的内容包装和投递协议。本文中我将聊一聊为什么使用RSS以及如何通过RSS订阅本博客。

为什么要使用RSS

首先说一说普遍的意义，RSS可以提高信息获取效率。

我不时通过抖音、b站、知乎等平台的推送获取信息，但是一般刷四五条才能看到感兴趣的信息。随着使用时间越来越长，兴趣基本被耗光了，但是之前那套滑动手指-获得快感的反射已经在脑海中建立，于是我麻木地重复着这套动作，重复得筋疲力竭。

RSS就像这些平台的关注页面，它迫使你仅从亲自筛选过的信息源中获取信息，与平台的不同点在于：平台关注页面的信息源是封闭生态中的创作者，而RSS的信息源则是广阔的互联网世界（理论上互联网上的信息源都可以使用RSS订阅）。

再者，RSS只会提取信息源中的标题、正文信息，再将其显示在阅读器统一的UI中，因此我们不必被不同网站五花八门的UI所干扰。

对我个人而言，我只是想让移动端可以更方便地访问我的博客，毕竟移动端的网页访问体验不是很好。

如何通过RSS订阅本博客

市面上有许多阅读器，包括移动端orPC端，开源or收费，不同UI风格的。在安卓端博主推荐一款精致小巧的开源RSS阅读器——ReadYou，点开链接后，径直往下滑看一看到一个”GET IT ON GitHub”，点击后选择最新版本的apk文件下载即可。

安装并打开ReadYou后，点击右上角加号，输入博客的RSS订阅地址https://enndermann.github.io/atom.xml，点击搜索就大功告成了。

台球的心法

发表于 2025-01-26 分类于 体育 本文字数： 449 阅读时长 ≈ 2 分钟

最近我的台球技术有了阶段性的提升，甚至在误打误撞之下完成了人生中的第一杆清台。提升的原因不在台球之中，而在台球之外——在于对身体和心态的调控。

从第一性原理出发，将母球以预想的状态击出，关键在于出杆的平直，如何做到出杆平直呢？关键在于让身体处于一个最佳的姿态，能够将球杆笔直地送出。调整两脚连线与出杆方向之间的夹角，找到最舒服和放松的状态，确保主视眼、手架、握杆手臂的方向以及球杆的方向在一条直线上。这是技术层面的基础，也是稳定发挥的前提。

然而，将客观条件调整到最优后，能否真正发挥出来，还取决于心法。在不击球的时候，需要做好规划，思考链接的顺序、球形的难点、下一球的杆法与力道。而当俯身准备击球时，心中只需专注于力度和打点，注意力在母球和目标球上切换，确保出杆方向与母球、假想球连线一致。至于之前的规划、球能否进袋等杂念，统统要抛之脑后。

其实人生的心法和台球的心法并无二致，都可以总结为“谋定后动，动则忘忧”。我自己常常就是吃着碗里的看着锅里的，总是让过去的遗憾和未来的焦虑降低了行动的效率。留专门的时间做好长期和短期的规划，真正开始行动时，暂时放下过去和未来，集中注意力完成当下的规划即可。

做事情的状态

发表于 2024-12-21 分类于 自我观察 本文字数： 427 阅读时长 ≈ 2 分钟

我发现我做事情的状态可以分为三种：满血状态，残血状态和机械状态。

满血状态是精力体力最好的状态，一般是休息结束或者运动后。此时大脑可以很好地梳理目前并行的所有的任务，做出合理的统筹，也可以专心做某件事。这时候时候做一些需要丰富联想的事，比如创造，理解，规划等等。

残血状态是精力体力下滑的状态。脑海中还会有好多任务泡泡围着我转圈，但是我已经没法雨露均沾了，一般是东敲一榔头西敲一榔头，没什么。既然这样就不要再勉强自己了，可以搞点小爱好，找人撩骚啊，打球啊，逛论坛，倒腾软件啊什么的。

机械状态是精力体力快要见底的状态，是三者里最好玩的。在疲劳的状态下，脑子无法再想杂七杂八的事情，只能单线程思考，碰巧就可以将注意力集中到一件事上，效率反而得到提升。一般11点过后进入深夜，我就进入了机械状态。机械状态特别适合对付那种死难死难或者特耗精力的任务，比如搞好博客的配置，调好模型的参数。我深有体悟的原因是，最近一个万字报告就是两个深夜肝出来的，博客界面也是熬夜配好的。

弄清楚自己的状态，我们就可以“哄”着这个时不时就犯懒摆烂的脑子，因状态制宜地做事情啦

Next主题原生的字体是Microsoft YaHei，我觉得霞鹜文楷在屏显上更好看一些，于是展开了一番折腾。

Font配置

字体有关的设置都在themes/next/_config.yml中，默认配置如下：

为了自定义配置，需要将enable设置为True，NexT 开放了 5 个特定范围的字体设定，他们是：

  • global字体：定义的字体将在全站范围使用
  • title字体：站点标题所使用的字体
  • headlines字体：文章内标题的字体（h1, h2, h3, h4, h5, h6）
  • posts字体：文章正文所使用的字体
  • codes字体： 代码块所使用的字体

各项所指定的字体为首选字体，若不可用，则使用内部默认字体。我们在配置时，在family下添加我们在google fonts挑选的字体比如LXGW WenKai、Noto Serif SC即可。

在博客页面对某段文字点击检查，font-family即为配置的字体，比如我博客正文的font-family：LXGW WenKai, "PingFang SC", "Microsoft YaHei", sans-serif，假如没有在CDN中找到LXGW WenKai，浏览器就会依次尝试加载后面的字体。

Next默认从fonts.googleapis.com中加载字体，然而在国内该链接可能不稳定，NexT 通过设置 font.host 来支持字体库的自定义 URL。国内有大佬搭建了fonts.googleapis.com的镜像站点：//fonts.loli.net。

CDN配置

一般来说到这里就没问题了，但是在我完成上述配置之后字体没有改变。这是因为Next默认的CDN无法连接，需要更换CDN。

CDN的相关配置在themes/next/_config.ym的vendors项中。其中internal为Next内部字体的CDN，plugins为第三方插件的CDN。Next给出的选择有local（默认CDN）、jsdelivr、unpkg、cdnjs、custom，如果要选择第三方CDN就添加custom并在custom_cdn_url这里添加相应的URL。（注意提示：如果使用的是最新版本的NexT，将internal设置为local。博主这里选择的CDN是unpkg。
