## 陪读蛙

陪读蛙是一款沉浸式翻译的开源平替插件。相比沉浸式翻译的愈加臃肿和商业化，陪读蛙的功能、界面则更加简洁。

另外，沉浸式翻译的变化像是国产软件格局的一个缩影。目前许多大厂都想打造一个超级app，购物app变成短视频app，外卖app变成金融app……或许对于用户而言，将一个特定需求做好的产品才是优秀的产品。

链接：https://www.readfrog.app/zh

## 横纵分析法

一个深度调研的skill，此外作者也提供了轻量化的prompt。通过横向和纵向两个维度讲清楚一个概念。我用gemini 3.1pro搭配该提示词调研了图神经网络，效果很不错。调研结果适合作为从零搞懂一个领域的入门文档。

> 想搞懂一个产品 / 公司 / 概念 / 人物到底是怎么回事，丢给它就行。
>
> 它会同时跑两条线：**纵向**把研究对象从诞生讲到当下，像讲故事一样把演变讲完整；**横向**把同期所有主要竞品摆出来逐一对比。最后两条线一交叉，能看出一些只看现状或只看历史看不出来的东西。
>
> 最后给你一份**排版精美的 PDF 研究报告**，10,000–30,000 字。
>
> **适合**
>
> - 调研竞品 / 调研一个新概念 / 调研一个公司
> - 写作前期需要系统性的素材准备
> - 对一个领域想从零搞懂
>
> **不适合**
>
> - 单纯查个名词解释 — 那种问题用普通对话就行，杀鸡用牛刀
> - 写公众号文章 — 那个用下面的 khazix-writer

链接：https://github.com/KKKKhazix/khazix-skills

## 程序员做饭指南

作者以产品使用文档的风格重新整理了大量菜谱，详细记录了需要准备的工具、调味料用量和操作步骤。

> 最近宅在家做饭，作为程序员，我偶尔在网上找找菜谱和做法。但是这些菜谱往往写法千奇百怪，经常中间莫名出来一些材料。对于习惯了形式语言的程序员来说极其不友好。

> 所以，我计划自己搜寻菜谱并结合实际做菜的经验，准备用更清晰精准的描述来整理常见菜的做法，以方便程序员在家做饭。
>
> 同样，我希望它是一个由社区驱动和维护的开源项目，使更多人能够一起做一个有趣的仓库。所以非常欢迎大家贡献它~

可视化网页：https://howtocook.aiursoft.com/

仓库链接：https://github.com/Anduin2017/HowToCook

## LRC Maker

一首喜欢的歌曲在网易云上没有歌词，而且在公开网络上找不到带时间轴的歌词，没办法只能自己制作。LRC Maker是一个功能齐全的滚动歌词制作工具，并且提供网页版供用户使用。

整个流程十分简单：上传音频文件->粘贴歌词->人耳根据音乐打时间点->导出.lrc文件

## 科研写作助手 (Research Writing Assistant)

![RWA](https://p.sda1.dev/32/ee76ce17bddd506b6d44b75ffb62b518/rwa_workflow.png)

> 这不是一个"只会润色句子"的提示词包，而是一套完整的科研写作协作系统。
> 它会在任务开始前先对齐目标与约束，通过头脑风暴确认论文类型、研究背景、方法和章节结构，再按学科和任务路由到对应技能模块执行。
>
> 如果你在做毕业论文、课程项目论文或投稿初稿，这个 Skill 会比普通对话式写作工具更稳定，因为它强调流程、记录和回写，不依赖单轮记忆。

最近撰写论文时，需要AI基于项目内容生成文档。对于小型文档，使用简单的提示词就可以获得满意的效果。一旦项目规模变大，文档内容达到数万字，未经规范的AI就容易出现前后用词不统一、编造事实等问题。该skill经过测试，所生成的文档相较默认情况文笔大有提升。

以codex为例，可以将仓库导入到当前项目中，直接告诉AI `SKILL.md`的文件路径，并要求按照该skill执行用户的指令即可。

链接：https://github.com/Norman-bury/research-writing-skill

## Nvidia NIM API

之前一直在用美团的免费模型接入沉浸式翻译，但是美团宣布即将停止提供免费API。

发现英伟达提供了许多开源模型的API（包括Deepseek v4 flash/pro，GLM 5.1， Gemma4等等），并且容易操作，使用邮箱注册并绑定手机号即可。额度近乎近乎无限，支持高并发，支持境内访问，很适合接入翻译工具。

注册地址：https://build.nvidia.com/settings/api-keys

## 环淀山湖

某天有空，骑车去淀山湖环绕一圈。在湖东南侧的朱家角出发，沿着沪青平公路一路西行。一路上都在施工，所以几乎看不到湖景。到了元荡湖向北拐，路况好了起来，非机动车道足有四五米宽。不一会又拐入滨水小道，一边风驰电掣，一边欣赏湖天相融的美景，真是心旷神怡。北段的水景相对平庸，东段景色也不错，但是游客更多。
