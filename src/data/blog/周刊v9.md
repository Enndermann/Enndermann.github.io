# 有趣的项目

## 谷歌连续发布三项AI产品

上一周，谷歌接连发布了新模型Gemini3 Pro、IDE产品Antigravity和图片生成模型Nano Banana Pro。据谷歌数据，Gemini3 Pro几乎在所有大模型能力指标上达到第一。

实测下来，Gemini3 Pro的语言表达能力、逻辑推理能力有了明显的提升。但是根据Linux DO论坛上的测试，Gemini 2.5 Pro的上下文范围为100k，而3的范围仅为30-40k，这一减少会极大限制模型的实际应用场景。

Antigravity似乎对账号资格有着严格的限制（或者是Bug），我折腾一番还是无法登录。

## 护眼姬

项目地址：https://github.com/avestura/EyesGuard

> Eyes Guard is a Windows Application for protecting your eyes. It will help you (also can force you!) to break if you are working with your PC for a long time using configurable times.

我每天有大量时间花在电脑屏幕前，出于健康考虑需要控制久坐的时间，因此需要一款提醒软件。`EyesGuard`支持自定义小型、大型休息时间，而且提示语非常幽默。该项目即在GitHub开源，也可以在Windows商店安装。

最近在和朋友玩双影奇境，它奇妙的关卡设计让我直呼过瘾。

最好玩的一关当属主角变成了两只猪，一只猪可以放彩虹屁（而且有很真实的屁声），一只猪可以增高。我刚好操控的是会放彩虹屁的猪，滑稽的音效让我们笑得停不下来。

之后的剧情也十分搞笑，我在这里就不过多剧透了。

##工程师学声乐

链接：https://zhuanlan.zhihu.com/p/31841346

一位音乐领域的工程师想要学习声乐，但苦恼于目前声乐教程大都偏向主观感受，如打哈欠发声，闻香发声，推开窗发声等。于是他试图借助工程思维和物理学方面的知识，建立一套有明确操作步骤、有客观判断指标的声乐学习方法。

该教程的优点是理论推理坚实，实操性强，有客观的判断标准。但是，该教程的理论体系仍不完善，如果加入生理学的知识，气息控制方法或许会更加科学。

## 不要被结果约束

链接：https://www.zhihu.com/question/365459892/answer/1960245432723677583

这篇文章就“丁克思维”和“结果丁克”进行了讨论，判断有“丁克思维”的人更加容易后悔。

> 丁克本质上应该是一种结果，而不是一种决定。它是你人生发展到某个阶段，自然导向的状态，而不是你在二三十岁时拍脑袋定下的计划。那些后悔的人，其实都在一开始就误判了丁克的意义，他们对这种生活的幸福预期，太高了。

这让我想起某个暑假，一位美国某大学的教授来我校讲座。在讲座之始，他发起了一个问答“你认为十年后的自己应该是怎么样”。答案五花八门——“在某一线城市”“在某行业”“在某职位”。对于这些答案教授没有发表评论，而是对另一个答案表示赞同——“尝试不同的工作和生活方式，找到自己喜欢的一种”。

这两件事其实都指向同一种生活态度，不要被一个确定的结果限制自己的选择，而是保持尝试和体验，向外探索世界，向内探索自我。这也是我所向往的。
