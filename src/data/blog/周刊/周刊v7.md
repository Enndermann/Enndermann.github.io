# 有意思

## 擦屁股理论

知乎上有个问题“你怎样拒绝奶头乐”，有个答主的观点非常有意思：

>**不拒绝。**
>
>我有一个有点恶心的理论，叫做擦屁股理论。
>
>这个理论的核心是：如果你想把一张纸完全不浪费的情况下擦完屁股，那你一定会弄得满手都是。
