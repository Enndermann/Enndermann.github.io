# 碎碎念

原以为毕业是欢乐而又轻松的，然而六月的琐事一件接一件，令人闲不下来。回到家竟有种打心底劳累的感觉。

这个假期是一个重新调整的好机会。好好睡觉，好好吃饭，适量运动，家附近的河边修了很美丽的跑步道，很适合每天运动。

# 莫向外求

在杭州逛完法喜寺要出寺门时，看到寺门背面写有“莫向外求”，觉得很有道理。

# 西湖烟雨

第三次来西湖了，依旧看不厌这里的湖光山色。

我是早晨五点骑车过去的，看到湖面的第一眼我愣住了。骤雨初歇，天光透过氤氲的水汽洒在湖面上，泛起大片大片的白光。此刻的西湖仿若仙境，而我却像误入的凡人了。

随后沿湖边顺时针走，雷峰塔和西面群山显出一点点轮廓，层层叠叠，或明或暗，像极了中国画中简笔勾勒的线条。

![西湖](https://res.cloudinary.com/dzkhc6ugx/image/upload/v1783698720/西湖_pcqeww.jpg)

# 青山绿水是安吉

安吉的丘陵上长满了竹子和茶树。驾车穿行其间，两侧的绿色向后退去，前方的绿色又涌上来，像是在绿色的海洋中前进。

接着向山上开去找一家“云边的咖啡厅”。上山的道路是水泥铺的，坡陡弯急，给驾驶带来了极大的挑战。到了山顶，人被狂风吹得东倒西歪，好像来到了什么禁地。

咖啡厅建在山顶附近的缓坡上，坡前有一片草地高台。站在高台上，安吉的山水便一层层铺开在眼前。恰逢云开雨霁，阳光先是照亮了一座山头，随着云层散开，将漫山遍野都渲染为金绿色。眼前的景象辽阔而又舒展，心境也随之开阔，甚至想高歌一曲“沿着江山起起伏伏温柔的曲线，放马爱的北国、爱的中原和江南”。

# 寻一抹北京红

北京的底色好像是红色的。

要找这抹红，最先可以想到故宫。故宫的红是饱经沧桑的朱红。走在其中，最吸引我的是它对对称的极致追求。从午门沿着中轴线走到御花园，两侧的宫殿排列有序，中央的大殿威严伫立。整个建筑群充满着秩序感。

北京的红也只不在深宫大院。街头巷尾的南门涮肉，也常以红色作装饰。那里的红色要活泼些，让我想到一路遇见的北京人，大开大合。

当然，天安门广场的红色是最正的。眼前是鲜红的国旗，远处是深红的城楼，两侧是神庙般壮观的人民大会堂和国博，向东还能望到朝阳CBD的高楼。站在广场中央，仿佛站在过去、现在与未来的交汇点上，想起国博一楼挂着的《沁园春·雪》：俱往矣，数风流人物，还看今朝。
