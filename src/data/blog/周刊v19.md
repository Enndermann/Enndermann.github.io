# 项目

# Zhihu++

> 注重隐私、互联网个人权利和无广告的知乎客户端

之前有推荐过一款第三方知乎客户端hydrogen，界面和功能很简约，但是后来可能是由于知乎API的变化，经常出现回答界面无法加载、重复推荐的问题。

与Hydrogen相同，Zhihu++也采用Material的UI风格，提供屏蔽开屏广告、按关键词、用户名、点赞评论数屏蔽回答的功能。

此外，Zhihu++解决了前面提到的两个问题，并且拥有独立的推荐算法，可以把内容推荐完全放在本地。总的来说，注重隐私、无广告、简约是Zhihu++的主要特色。
