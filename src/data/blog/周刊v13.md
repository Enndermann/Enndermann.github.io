# Antigravity Manager

> **Antigravity Tools** 是一个专为开发者和 AI 爱好者设计的全功能桌面应用。它将多账号管理、协议转换和智能请求调度完美结合，为您提供一个稳定、极速且成本低廉的 **本地 AI 中转站**。
>
> 通过本应用，您可以将常见的 Web 端 Session (Google/Anthropic) 转化为标准化的 API 接口，彻底消除不同厂商间的协议鸿沟。

众所周知，Antigravity为学生用户提供了较为慷慨的模型额度。但是Antigravity也有一些缺点，诸如只能通过TUN模式使用，并且截断问题频发。

该项目通过反向代理实现了Antigravity to API，尤其对于手头额度并不宽裕的同学来说，极大地拓展了AI的使用场景。且该项目支持管理多个账号，所以有一种玩法就是：**通过家庭组创建多个账号，负载均衡使用，从而实现额度自由。**

![反重力API](https://github.com/lbjlaq/Antigravity-Manager/raw/main/docs/images/dashboard-light.png)

链接：https://github.com/lbjlaq/Antigravity-Manager

## `CefFlashBrowser`

> `CefFlashBrowser`是一个自带 Flash Player 插件的浏览器，可以正常显示网页上的 Flash 内容，此外还支持打开本地 SWF 文件，管理 Flash 游戏存档等。

4399上大部分游戏需要安装flash插件，而4399推荐的flash中心是一个流氓软件。而`CefFlashBrowser`作为一个轻量化、**自带flash插件**的浏览器，恰好满足了我重温童年的需求。

链接：https://github.com/Mzying2001/CefFlashBrowser/

## Notion初体验

这段时间对知识管理很着迷。之前我零零散散写过一些md笔记，分布在手机、电脑的各个软件、文件夹中，既不利于维护，也不利于建立知识体系。这时，一种双链笔记的方法吸引了我的目光，对于每个知识块（Notion、obsidian、logseq中均有类似的元素，只不过叫法不同），可以建立指向其它知识块的超链接，也可以看到链接本知识块的其它块，相当于将知识建模为一个**双向图**，这非常有利于我们将不同时期、不同领域、不同媒介上获得的知识建立联系。

而Notion相较于其它同类型笔记软件来讲，最大优势就是学生可**免费**申请会员资格。于是可以拥有：

- 超大的**云端存储**空间
- 实时**多端同步**
- **多模态、多视图**的知识库
- 一定额度的Notion AI（搭配知识库实现**RAG**效果更佳）

不过，试用了多个笔记软件和知识管理方法后，我的体会是：想要提升扩充自己的知识体系，最重要的并不是选择什么工具、什么方法，而是要有一颗**乐于折腾、善于思考、勤于记录**的心。

## 搓小游戏

最近和大哥聚一块，用Antigravity搓出了两个小时候发明的游戏。不由得感叹在vibe coding的加成下，想法落地的速度之快。2025是vibe coding爆发式发展的一年，如果这一年能提早到我小学初中的时候，想必就可以把当时的许多奇思妙想付诸实践了。

![弹珠对决](https://p.sda1.dev/30/3ec02d57ecca397f987ecf3cd72d3903/弹珠对决.png)

> 弹珠对决：一款核心玩法为用己方弹珠将对方弹珠打出地图的游戏。另外加入了若干机制增加趣味性和博弈复杂度。在小学时我们还是用玻璃棋子和麻将完成的。

![](https://p.sda1.dev/30/761a4dba702e82b37a3b2a8eba60fdf7/狼人传说.png)

> 狼人传说：一个回合制卡牌对战游戏，核心玩法就是用警察找对方的狼人，用狼人杀对方的人，先杀死对方狼人的一方获胜，另外加入了几十种特殊技能角色、ban选环节以增加博弈难度。记得小时候是用狼人杀的卡牌实现这一想法的，但玩法其实与狼人杀半毛钱关系都没有。
